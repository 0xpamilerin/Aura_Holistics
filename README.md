# Aura Holistic & Wellness — Clinic Web Platform

Modern, responsive multi-page web platform for a traditional holistic wellness & acupuncture practice. Designed as a high-end showcase of healthcare UI/UX, appointment booking flows, and botanical e-commerce catalogue filtering.

## Included Pages & Features

* **Home (`index.html`)**: Hero section, floating treatment highlights, clinical philosophy, core service overview, stats, featured herbal blends, and client testimonials.
* **About (`about.html`)**: Clinic story, philosophy, practitioner profile, and core values.
* **Patient Stories (`patient-stories.html`)**: HTML5 video testimonials with client recovery journeys.
* **Services Hub (`treatments.html`)**: Comprehensive catalogue of all 9 specialized clinical treatments.
* **Treatment Detail Pages**:
  * Acupuncture (`acupuncture.html`)
  * Cupping Therapy (`cupping.html`)
  * Moxibustion (`moxibustion.html`)
  * Herbal Consultation (`herbal-consultation.html`)
  * Reflex Therapy (`reflex.html`)
  * Healthron Electro-Therapy (`healthron.html`)
  * Steam Sauna Therapy (`steam-sauna.html`)
  * Ionic Foot Detox (`ionic-detox.html`)
  * Dietetics & Nutritional Planning (`dietetics.html`)
* **Interactive Appointment Booking (`appointment.html`)**: Multi-step booking wizard, dynamic service pre-selection from treatment pages, interactive time-slot chip picker, date constraint validation, and confirmation receipt state.
* **Herbal Catalogue (`catalogue.html`)**: Over 70 herbal products with real-time keyword search, multi-category filtering (Teas, Capsules, Supplements & Other), and responsive card grids.
* **Product Details (`product.html`)**: Dynamic product display driven by URL search parameters with ingredient, usage, and disclaimer layouts.
* **Clinical Research (`research.html`)**: CEO & clinical research whitepaper studies with modal preview.
* **Contact (`contact.html`)**: Location details, opening hours, interactive contact inquiry form.
* **FAQ (`faq.html`)**: Accessible accordion with animated disclosure indicators.
* **Legal**: Privacy Policy (`privacy.html`) and Terms of Use (`terms.html`).

## Running Locally

Open `index.html` directly in any modern browser, or launch using VS Code Live Server / any local HTTP server.
